# 📚 AI Engineer Course Platform

A modern Next.js 14 web application providing an interactive learning experience across all 10 AI Engineering modules.

## ✨ Features
- **Interactive Dashboard** with progress bars, study streak tracking, and quick resume.
- **Curriculum Catalog** with search, difficulty filtering, and lesson lists.
- **Lesson Learning Environment** with syntax-highlighted code snippets and mark-as-done state.
- **Local Progress Persistence** via `localStorage` (no account required).
- **Curated Resource Library** with categorized papers, frameworks, and tools.
- **Dark Mode UI** crafted with Tailwind CSS and Lucide icons.

## 🚀 Setup & Execution
```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your web browser.

## 📦 Deployment
Deploy with zero configuration to **Vercel** or **Railway**.
